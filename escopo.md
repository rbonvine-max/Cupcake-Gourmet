# ESCOPO DO PROJETO
## Sistema de Gestão para Loja Virtual de Cupcakes

### 1. Apresentação

O presente projeto tem como finalidade desenvolver um sistema de gestão para uma loja virtual especializada na comercialização de cupcakes. A proposta consiste em criar uma plataforma digital que permita aos clientes visualizar produtos, consultar informações, realizar pedidos e acompanhar suas compras.

O sistema também contará com um ambiente administrativo destinado ao gerenciamento dos produtos, clientes, estoque e pedidos, proporcionando maior organização e eficiência nos processos comerciais da loja.

### 2. Problema identificado

Pequenos estabelecimentos comerciais que trabalham com a produção e venda de produtos alimentícios podem enfrentar dificuldades no gerenciamento de pedidos, controle de estoque, cadastro de clientes e acompanhamento das vendas.

A ausência de uma ferramenta informatizada pode ocasionar falhas nos registros, dificuldades na organização das informações e demora no atendimento aos clientes.

Diante desse cenário, identifica-se a necessidade de desenvolver uma solução tecnológica que centralize essas atividades e facilite a administração de uma loja virtual de cupcakes.

### 3. Objetivo geral

Desenvolver um sistema de gestão para uma loja virtual de cupcakes, utilizando conceitos e técnicas de Engenharia de Software, com o propósito de organizar os processos de comercialização, gerenciamento de produtos, controle de pedidos, clientes e estoque.

### 4. Objetivos específicos

- Desenvolver uma interface intuitiva e acessível para os clientes.
- Permitir o cadastro e a consulta de produtos.
- Disponibilizar um catálogo virtual de cupcakes.
- Implementar um carrinho de compras.
- Possibilitar o registro e gerenciamento de pedidos.
- Permitir o cadastro e gerenciamento de clientes.
- Desenvolver funcionalidades para controle de estoque.
- Disponibilizar uma área administrativa para gerenciamento da loja.
- Organizar as informações por meio de um banco de dados.
- Aplicar técnicas de testes para verificar o funcionamento do sistema.

### 5. Público-alvo

O sistema será destinado a dois grupos principais:

**Clientes:** pessoas interessadas em consultar e adquirir cupcakes por meio de uma plataforma virtual.

**Administradores:** responsáveis pelo gerenciamento da loja, incluindo produtos, clientes, estoque, pedidos e acompanhamento das vendas.

### 6. Escopo funcional

O sistema deverá contemplar as seguintes funcionalidades:

**6.1. Área do cliente**
- Cadastro de clientes.
- Login e autenticação.
- Consulta ao catálogo de cupcakes.
- Visualização de preços e descrições.
- Pesquisa de produtos.
- Adição e remoção de produtos no carrinho.
- Registro de pedidos.
- Consulta ao histórico de compras.
- Acompanhamento do status dos pedidos.

**6.2. Área administrativa**
- Cadastro, edição e exclusão de produtos.
- Gerenciamento de categorias e sabores.
- Controle de estoque.
- Consulta aos clientes cadastrados.
- Visualização e gerenciamento de pedidos.
- Atualização do status dos pedidos.
- Consulta às vendas realizadas.
- Emissão de relatórios gerenciais.

### 7. Escopo técnico

O desenvolvimento do projeto deverá contemplar:

- Levantamento e documentação de requisitos.
- Modelagem de processos e diagramas UML.
- Prototipação das interfaces do sistema.
- Modelagem conceitual e lógica do banco de dados.
- Desenvolvimento do banco de dados físico.
- Implementação das funcionalidades.
- Realização de testes de software.
- Documentação técnica do sistema.

### 8. Limitações do projeto

Para manter o desenvolvimento compatível com os objetivos acadêmicos e o tempo disponível, inicialmente não estão previstas:

- Integração com plataformas externas de pagamento.
- Aplicativo nativo para dispositivos móveis.
- Integração automática com serviços de entrega.
- Integração com sistemas contábeis externos.

Essas funcionalidades poderão ser consideradas em futuras versões.

### 9. Resultados esperados

Espera-se obter um sistema funcional capaz de organizar as principais atividades de uma loja virtual de cupcakes, proporcionando maior controle administrativo, facilidade na realização de pedidos e melhor organização das informações comerciais.

O projeto também deverá demonstrar a aplicação prática dos conhecimentos adquiridos na disciplina de Engenharia de Software, desde o planejamento até a implementação e os testes da solução.

### 10. Considerações finais

O desenvolvimento deste sistema representa uma oportunidade de aplicar conceitos fundamentais de Engenharia de Software na construção de uma solução tecnológica voltada ao comércio eletrônico.

Por meio do projeto, pretende-se demonstrar a importância do planejamento, da documentação, da modelagem e da implementação de sistemas informatizados para atender às necessidades de um negócio.
