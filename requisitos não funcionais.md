# REQUISITOS NÃO FUNCIONAIS
## Sistema Cupcake Store

### 1. Introdução

Este documento apresenta os requisitos não funcionais do sistema Cupcake Store, estabelecendo critérios relacionados à qualidade, segurança, desempenho, usabilidade, compatibilidade e confiabilidade da aplicação.

Esses requisitos têm como finalidade garantir que o sistema funcione adequadamente, oferecendo uma experiência satisfatória aos clientes e administradores.

### 2. Requisitos não funcionais

#### 2.1. Usabilidade

**RNF01 – Interface intuitiva:** O sistema deverá apresentar uma interface simples, organizada e intuitiva, facilitando a navegação dos usuários.

**RNF02 – Facilidade de utilização:** As funcionalidades deverão ser apresentadas de maneira clara, permitindo que os usuários realizem suas operações sem dificuldades desnecessárias.

**RNF03 – Padronização visual:** O sistema deverá manter um padrão visual consistente entre suas páginas, menus, botões e formulários.

#### 2.2. Segurança

**RNF04 – Proteção de senhas:** As senhas dos usuários deverão ser armazenadas utilizando mecanismos seguros de hash, não sendo permitido armazená-las em texto simples.

**RNF05 – Controle de acesso:** O sistema deverá restringir o acesso às funcionalidades administrativas aos usuários devidamente autorizados.

**RNF06 – Proteção de dados:** O sistema deverá adotar medidas de segurança para proteger as informações pessoais dos clientes.

**RNF07 – Validação de informações:** O sistema deverá validar os dados informados pelos usuários, evitando registros incorretos ou inconsistentes.

#### 2.3. Desempenho

**RNF08 – Tempo de resposta:** O sistema deverá apresentar respostas em tempo adequado durante as operações de consulta, cadastro e navegação.

**RNF09 – Processamento de pedidos:** O sistema deverá processar os pedidos de maneira consistente, evitando duplicidade de registros e inconsistências de estoque.

#### 2.4. Compatibilidade

**RNF10 – Compatibilidade com navegadores:** O sistema deverá funcionar nos principais navegadores modernos, como Google Chrome, Mozilla Firefox e Microsoft Edge.

**RNF11 – Responsividade:** A interface deverá adaptar-se a diferentes tamanhos de tela, incluindo computadores, tablets e smartphones.

#### 2.5. Confiabilidade e integridade

**RNF12 – Integridade dos dados:** O sistema deverá garantir a consistência das informações armazenadas no banco de dados.

**RNF13 – Tratamento de erros:** O sistema deverá apresentar mensagens claras quando ocorrerem erros durante a utilização.

**RNF14 – Integridade dos pedidos:** O sistema deverá garantir que os valores e os produtos registrados nos pedidos permaneçam consistentes após a confirmação da compra.

#### 2.6. Manutenibilidade

**RNF15 – Organização do código:** O código-fonte deverá ser organizado e estruturado, facilitando futuras alterações e correções.

**RNF16 – Documentação técnica:** O projeto deverá possuir documentação que facilite a compreensão e a manutenção do sistema.

### 3. Considerações finais

Os requisitos não funcionais estabelecem os critérios de qualidade necessários para o desenvolvimento do Cupcake Store, contribuindo para a segurança, facilidade de utilização, confiabilidade e manutenção da aplicação.
